# DS_Library

C++ library for custom data structures for use in personal projects

## What this does
This project is meant to deepen my understanding of data structures and the code behind them. Once finished, you will be able to move the header file of your choice into your project and implement them as you would a normal data structure.

## Features
- Vector implementation

## Tech
C++ for the libraries and unit testing

## Getting started

## Prerequisites
- C++ 15 or greater

## Installation
1. Clone the repository  
'''  
git clone https://github.com/dylanc0628/DS-library  
Add the repository into your project   
Add #include "header.h" (replace header with the library of your choice) into your main.cpp  
'''

## Testing
Tests are included under "unit_tests.h" and in "main.cpp" in each folder.
